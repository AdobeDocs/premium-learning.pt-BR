# Saiba antes de ir: cursos ao vivo de instrutor - Visão geral

Prepare-se para uma jornada de aprendizado bem-sucedida antes de participar de um curso de instrutor ao vivo. Selecione o nome do tópico vinculado (as primeiras palavras de cada item) para ir até essa seção.

* [Prepare-se para um curso de instrutor ao vivo](/help/main-guide/live-instructor-course-readiness/course-preparation/prepare-for-live-instructor-course.md): Saiba o que esperar depois de se inscrever, como acessar o ambiente de classe e como obter um treinamento bem-sucedido.
* [Participe de uma sessão ao vivo do curso de instrutor](/help/main-guide/live-instructor-course-readiness/course-preparation/join-live-instructor-course-session.md): Descubra como participar da sua sessão ao vivo no dia da aula, incluindo etapas de backup se o convite do calendário estiver ausente.
* [Requisitos de sistema do curso de instrutor ao vivo](/help/main-guide/live-instructor-course-readiness/system-requirements/live-instructor-course-system-requirements.md): Verifique os requisitos de Adobe Connect, hardware e software que se aplicam a todos os cursos de instrutor ao vivo.
* [Requisitos adicionais do sistema por solução](/help/main-guide/live-instructor-course-readiness/system-requirements/additional-system-requirements-by-solution.md): revise os requisitos adicionais para o AEM Edge Delivery Services Development, AEM Sites, Campaign, Experience Platform e Target.
