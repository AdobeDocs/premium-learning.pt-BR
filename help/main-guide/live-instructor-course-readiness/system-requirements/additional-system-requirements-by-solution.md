# Requisitos adicionais do sistema por solução

## Desenvolvimento do Adobe Experience Manager Edge Delivery Services

É necessária uma conta GitHub pública e pessoal.

## Adobe Experience Manager Sites

Os alunos acessarão a conta da empresa Adobe Experience Manager da Premium Learning durante a duração da aula para concluir os laboratórios do curso.

Para cursos técnicos do Adobe Experience Manager, use o software de máquina virtual chamado **[!DNL ReadyTech]**. Antes da classe, verifique se você:

1. Concluir [Verificação Prévia de Desempenho](https://adobe.instructorled.training/system-precheck)
1. Conclua a Pré-verificação de Acessibilidade e verifique o acesso somente à [[!DNL ReadyTech] tela de logon](https://axis.readytech.com/#/login) (Não faça logon).

## Adobe Campaign

O cliente do Campaign é um aplicativo somente para Windows. Se você não tiver uma máquina Windows para instalar o cliente do Campaign, um ambiente virtual chamado **[!DNL ReadyTech]** será fornecido durante a aula.

Se você não tiver uma máquina com Windows ou a capacidade de instalar software, certifique-se de:

1. Concluir [Verificação Prévia de Desempenho](https://adobe.instructorled.training/system-precheck)
1. Conclua a Pré-verificação de Acessibilidade e verifique o acesso somente à [[!DNL ReadyTech] tela de logon](https://axis.readytech.com/#/login) (Não faça logon).

## Adobe Experience Platform

Alguns cursos técnicos do AEP usam o **Postman** para atividades relacionadas à API. Se você não tiver a capacidade de instalar no computador, receberá uma máquina virtual chamada **[!DNL ReadyTech]** durante a aula.

Se você não puder instalar o software, certifique-se de:

1. Concluir [Verificação Prévia de Desempenho](https://adobe.instructorled.training/system-precheck)
1. Conclua a Pré-verificação de Acessibilidade e verifique o acesso somente à [[!DNL ReadyTech] tela de logon](https://axis.readytech.com/#/login) (Não faça logon).

## Adobe Target

Recomendamos baixar e instalar estas extensões do Chrome:

* [Adobe Experience Platform Debugger](https://experienceleague.adobe.com/en/docs/experience-platform/debugger/home)
* [Adobe Target Visual Experience Composer](https://chromewebstore.google.com/detail/adobe-experience-cloud-vi/kgmjjkfjacffaebgpkpcllakjifppnca?pli=1)
