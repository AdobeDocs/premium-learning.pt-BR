# Requisitos do sistema para sessões ativas de coorte

## Prepare-se com o Adobe Connect

As sessões em tempo real serão conduzidas usando o Adobe Connect. Siga estes pontos de verificação para evitar problemas técnicos durante a sessão em tempo real:

1. Execute este [teste de diagnóstico](https://training.adobeconnect.com/common/help/en/support/meeting_test.htm) para garantir que o Adobe Connect esteja funcionando corretamente no seu sistema.
1. Consulte as [especificações técnicas](https://helpx.adobe.com/adobe-connect/connect-tech-spec/12-10-technical-specifications.html) do Adobe Connect.
1. Você pode associar-se ao Adobe Connect por meio de um navegador ou do aplicativo de desktop.
a) Se o aplicativo de desktop já estiver instalado e você estiver com problemas, desinstale o aplicativo Adobe Connect e reinstale-o usando a versão mais recente fornecida [aqui](https://helpx.adobe.com/in/adobe-connect/connect-downloads-updates.html).

Você encontrará o link personalizado da sala de reunião virtual no convite do calendário. No dia do treinamento, recomendamos iniciar o link de 5 a 10 minutos antes do início da aula.

## Requisitos de hardware

- Computador ou notebook com teclado e mouse
- 8 GB de RAM ou mais para obter o melhor desempenho do navegador
- Um segundo monitor externo é preferido
- Resolução mínima de 1280 x 768 pixels
- Conexão com a Internet de 100 Mbps ou mais

## Requisitos de software

- Os navegadores da Web recomendados são Chrome ou Firefox
- Capacidade de acessar a tela de logon do [Adobe CX Enterprise](https://experience.adobe.com/) (veja a observação abaixo)
- As informações de logon serão fornecidas durante o treinamento
- Acesso a um editor de texto
- Um programa para extrair arquivos (.zip)
- Um programa para ler PDFs, como o [Adobe Reader](https://get.adobe.com/reader/)

>[!NOTE]
>
>Não efetuar login. Basta testar se você pode acessar o link em seu navegador sem que a rede da sua empresa o bloqueie. Você poderá ver a mensagem &quot;o Adobe ID não está vinculado às contas da solução Adobe Experience Cloud&quot;, que é esperada. O link não tem como objetivo que os alunos acessem nada antes da aula. No primeiro dia de aula, o instrutor fornecerá as credenciais para fazer logon.
