# Expectativas de participação

**As sessões ativas são uma parte principal do coorte e a presença é esperada duas vezes por semana. A participação é rastreada com base somente na participação ao vivo.** Essas sessões interativas em tempo real oferecem a oportunidade de se envolver com especialistas da Adobe, fazer perguntas, participar de discussões e praticar com colegas. Embora as gravações das sessões estejam disponíveis para revisão, assistir a uma gravação não conta para a sua participação.

**O Capstone Project &amp; Peer Review é necessário para o crédito de conclusão.** Demonstre domínio através de um projeto de capstone guiado. Aplique seu aprendizado a um desafio do mundo real e, em seguida, troque feedback com seus colegas em sessões de análise estruturadas. Os alunos devem concluir o projeto principal para receber o crédito de conclusão de coorte.

**Módulos e questionários no Ritmo Individual são essenciais para se preparar para as sessões ao vivo e para concluir o projeto com êxito.** Aprenda de forma flexível, no seu próprio ritmo, entre sessões ao vivo. Acesse módulos assíncronos, laboratórios práticos e atividades de discussão para aprofundar sua compreensão e aplicar os principais conceitos em cenários reais.
